# Dog of Bitcoin community app store for umbrelOS

Add it on your Umbrel: Settings, App Store, Community App Stores, paste
`https://github.com/dogofbitcoin/umbrel-app-store`, then install **DOG Mode**.

Apps here:

- `dogofbitcoin-dogmode`: a DOG Mode node (Bitcoin Core 31.1 plus the DOG Mode relay policy), packaged the
  way the Bitcoin Knots app is: Umbrel's own Bitcoin Node interface with the DOG Mode client, its own ports
  so it runs beside the Bitcoin Node app, usable by apps that need a Bitcoin node. The client is built from
  source at a pinned commit by the Dog of Bitcoin Foundation (github.com/dogofbitcoin/docker-dogmode); the
  DOG Mode project has not cut a release yet, and this package is not an official release of theirs.

Maintained by the Dog of Bitcoin Foundation, dev@dogswap.io.
